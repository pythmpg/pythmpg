# PythMPG 1.1.0 Release Notes

## Added
- In module `mpg_dicts`, defines a new dictionary `mpg_alt_dict` via a call to new function `get_mpg_alt_dict`, containing alternative MPG names (e.g., `m3m`, `-4m2`, `2mm`) and their mappings to standard names.
- In module `mpg_tools`, uses new function `get_std_name` (which accesses `mpg_alt_dict`) to translate alternative MPG names to standard names. A notice is printed whenever an input name is changed.
- In module `mpg_tools`, removes spaces and periods (including a trailing `.1`) from input MPG names before matching them, so that, e.g., `m m m` is accepted as `mmm` and `m 3 m` as `m-3m`.
- In module `mpg_tools`, adds an option allowing the input parameter `mpg_list` of functions `get_mpg_info` and `get_num_indep` to be a single MPG name (string).

## Changed
- In module `parse_jahn`, provides improved error handling of unrecognized Jahn symbols. Symbols containing an asterisk (`*`) are reported as unsupported.
- In module `mpg_tools`, provides improved error handling of MPG names. An unrecognized name raises a `ValueError` naming the input, and an `mpg_list` that is neither a list nor a string raises a `TypeError`.
- The PDF User Guide has been updated.

## Fixed
- In module `mpg_tools`, incorporates minor typographical corrections in docstrings.

## Documentation
- Release notes are now included in the documentation.
- The documentation shows the package version at the top of the sidebar.
- Introductory material has been reorganized on the landing page.

## Packaging
- numpy 2.0 or later is now required at install time, as previously stated in the documentation.
- The PyPI page now shows the license, a project description, and links to the documentation, release notes, source code, and issue tracker.
