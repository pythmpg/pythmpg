# PythMPG 1.1.0 Release Notes

## Added
- In module `mpg_dicts`, defines a new dictionary `mpg_alt_dict` via a call to new function `get_mpg_alt_dict`, containing alternative MPG names and their mappings to standard names.
- In module `mpg_tools`, uses new function `get_std_name` (which accesses `mpg_alt_dict`) to translate alternative MPG names to standard names after issuing a warning.

## Improved
- In module `parse_jahn`, provides improved error handling of unrecognized Jahn symbols, including those with an asterisk.
- In module `mpg_tools`, provides improved error handling of unrecognized MPG names  .

## Fixed
- In function `get_mpg_info` of module ``mpg_tools`, constructs `bns_list` to be a list of empty strings if input parameter `mpg_list` is not the default "All".
- In module `mpg_tools`, incorporates minor typographical corrections.
